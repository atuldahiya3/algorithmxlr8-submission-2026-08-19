# Vasya and Socks

**Difficulty:** `Easy`

## Problem

Vasya has n pairs of socks. Every day he wears one pair. On days m, 2m, 3m, and so on, that evening his mother buys him one more pair.

Find the number of the last day on which Vasya has a pair of socks to wear.

Read two integers n and m from standard input, on one line. Print one integer, the number of days Vasya successfully wears a sock.

## Examples

### Example 1

**Input**
```
n = 2, m = 2
```
**Output**
```
3
```

**Explanation:** Vasya wears socks on days 1, 2, and 3 (gaining one back after day 2), and runs out on day 4.

### Example 2

**Input**
```
n = 9, m = 3
```
**Output**
```
13
```

**Explanation:** Following the same process, he makes it through 13 days before running out.
