# Boy or Girl

**Difficulty:** `Easy`

## Problem

You are given a nickname made only of lowercase English letters. Count how many distinct letters appear in it. If that count is odd, print "IGNORE HIM!". If it is even, print "CHAT WITH HER!".

Read the name from standard input, on one line. Print exactly one of the two texts above.

## Examples

### Example 1

**Input**
```
wjmzbmr
```
**Output**
```
CHAT WITH HER!
```

**Explanation:** The distinct letters are w, j, m, z, b, r, a total of 6, which is even.

### Example 2

**Input**
```
xiaodao
```
**Output**
```
IGNORE HIM!
```

**Explanation:** The distinct letters are x, i, a, o, d, a total of 5, which is odd.
